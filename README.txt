AUREL PRO — MULTI-PAGE PREMIUM AUDIO WEBSITE

Files:
- index.html          Home / cinematic landing page
- collection.html     Headphones, earphones and speakers catalog
- product.html        Dynamic product detail page (?id=noir-one etc.)
- technology.html     Technology / engineering page
- experience.html     Interactive sound room
- story.html          Brand story
- contact.html        Contact page
- style.css           Complete design system
- app.js              Navigation + fluid motion
- sound.js            Web Audio visualizer

HOW TO RUN:
1. Keep every file in the same folder.
2. Open index.html in your browser.
3. Click Collection, Technology, Experience, Story, Contact and individual products.
4. The Sound Room asks for a click before audio starts.

The product data in product.html is fictional demo content. Replace prices/specifications with your real product information before publishing.
